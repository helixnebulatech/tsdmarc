## What it does

<CardGrid stagger>
  <Card title="Every report type" icon="document">
    Aggregate (rua) reports in the draft, RFC 7489 and RFC 9990 schemas, failure
    (ruf) reports (RFC 6591 / RFC 9991) and SMTP TLS reports (RFC 8460),
    compressed or not, as files, emails or mbox archives.
  </Card>
  <Card title="Enriched data" icon="information">
    Reverse DNS, base domain, sending service name and type, country and ASN for
    every source IP, with an offline IPinfo Lite database available.
  </Card>
  <Card title="Mailboxes" icon="email">
    Read reports from IMAP, Gmail, Microsoft Graph (Microsoft 365) or a Maildir,
    archive what was processed, and watch for new reports.
  </Card>
  <Card title="Outputs" icon="rocket">
    JSON and CSV files, Elasticsearch 9, OpenSearch, Splunk HEC, PostgreSQL,
    Kafka, Amazon S3, Azure Log Analytics, Grafana Loki, syslog, GELF, webhooks
    and email.
  </Card>
  <Card title="Drop-in CLI" icon="seti:shell">
    The `tsdmarc` command reads parsedmarc's INI file and accepts both
    `TSDMARC_*` and `PARSEDMARC_*` environment variables.
  </Card>
  <Card title="Same output as parsedmarc" icon="approve-check">
    Output files, documents and payloads use parsedmarc's snake_case fields, so
    the premade Kibana, OpenSearch, Grafana and Splunk dashboards work
    unchanged.
  </Card>
</CardGrid>
